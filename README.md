# Cruce de usos de dispositivos

Recurso descriptivo para organizar usos académicos y no académicos declarados por las mismas personas en un mismo grupo y periodo.

https://krakaur.github.io/usos-dispositivos/

## Uso

Introduce cuatro recuentos agregados: ambos usos, solo académico, solo no académico y ninguno. La calculadora obtiene el total válido y los porcentajes de cada perfil. Distingue un cero real de un dato pendiente.

Puedes cargar un ejemplo ficticio, editar los campos de contexto, guardar un archivo JSON y volver a abrirlo, descargar un informe de texto o imprimir/guardar un PDF. La plantilla Excel descargable incluye una hoja vacía, un ejemplo ficticio y la documentación de fórmulas.

El guardado se realiza mediante archivos en el dispositivo. No hay base de datos, cuentas ni guardado automático en GitHub. Los datos introducidos se procesan en el navegador.

## Alcance

Se requieren respuestas válidas a ambas preguntas. Los porcentajes marginales no permiten recuperar los cuatro recuentos. Una respuesta ausente no se clasifica como No. La tabla describe coexistencia de usos declarados, sin demostrar simultaneidad, distracción, aprendizaje o causalidad.

El ejemplo contiene datos inventados. No se publican respuestas ni información identificable de participantes.

## Archivos

Sitio estático en index.html, sin dependencias. La plantilla Plantilla_cruce_usos_dispositivos_V01.xlsx es una copia idéntica del archivo previamente revisado, sin macros ni vínculos externos de datos. Incluye enlaces a la documentación de SUMA y SI de Microsoft.
